## 内容与使用边界

本批仅报道学习者和教师能直接使用的学习、伴学与备课功能，不纳入管理后台、资源治理、角色权限或内部技术改造选题。

- 英语跟读和单词本依赖相应语言服务启用，原合并记录明确默认关闭；稿件未宣称已对全部用户开放。
- Studio 受账号权限、材料类型和生成服务配置限制；稿件说明当前课件 PowerPoint 导出主要使用整页图像，未声称全部元素可编辑。
- 学习进度与已读标记不等同于知识掌握程度；自动摘要、发音评分与识词结果均保留人工核对的必要性。
- 情境式开头不是访谈或试用报告，不包含虚构学生身份、反馈或学习效果数据。

## 配图与审阅

每篇独立配备一张 AI 生成的概念编辑插画，采用 16:9 横构图，WebP 网页资源位于 `assets/news/release-*-v1.webp`。插画不是产品界面、真实学校、真实用户或活动照片；`cover_alt` 均明确标注概念插画。头图由文章元数据提供，正文不重复嵌入。

本批只提交原文，保留各篇独立的标题、摘要、稳定 slug 和翻译组标识。正文以 H2 开始组织章节，页面负责 H1；内链指向实际存在的课程目录、学习入口或已存在的课程导读，个人学习入口需要登录。

合并与发布仍按仓库既有审核流程进行；本草稿 PR 不请求自动合并或直接发布。
